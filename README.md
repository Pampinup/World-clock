# World Clock App 🕐🌍

A responsive web application that displays real-time clocks across multiple time zones around the world, allowing users to easily track time in different cities with a clean and intuitive interface.

## Features
- View current time in multiple cities
- Real-time clock updates
- Add and manage different time zones
- Simple and user-friendly interface
- Responsive design for all devices

## Tech Stack
- HTML
- CSS
- JavaScript
- Netlify
